# 企业级 AI 邮件运营助手文档基线

本目录是企业级 AI 邮件运营助手 Level 0（Step 001–005）的评审与验收入口。项目一期围绕 Gmail 邮件回复、飞书审批、知识库检索、自动跟进和最小客户画像展开；本批次只冻结范围、任务契约、用户验收、架构决策和数据安全边界，不代表运行时代码或生产环境已经完成。

## 文档关系

```text
一期范围冻结
      ↓ 约束任务边界
成功任务与风险矩阵
      ↓ 产出 UAT 任务与终态
用户旅程与 UAT 场景
      ↓ 验证架构边界
架构决策记录
      ↓ 固化数据访问和安全控制
数据分类与威胁模型
```

## 评审规则

1. 需求超出一期范围时，先记录为 `PROPOSED` 变更请求，不直接改一期 Gate。
2. 模型分类不能覆盖确定性风险规则；未定义任务、证据不足、权限不明或发送结果不确定时，默认人工/只读处理。
3. 文档静态检查通过只说明材料完整，不替代业务、技术、交付/QA 和安全责任人的签字。
