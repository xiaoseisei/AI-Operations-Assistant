## 已完成内容

- `Settings` 使用 Pydantic Settings，并拒绝未知环境变量字段。
- Offline 模式默认 `EMAIL_ADAPTER=mock`、`LLM_ADAPTER=mock`、`AUTO_SEND=false`，无需真实密钥即可自检。
- `AUTO_SEND` 只接受 `true`/`false`；`0`、`no`、`off`、`yes`、空值和任意其他字符串均拒绝。
- Offline 模式配置真实 Adapter 会失败；Real 模式必须显式使用 Gmail/Real Adapter。
- Real 模式缺少 Gmail、飞书或 LLM 任一必需 Secret 时拒绝启动，不降级到 Mock。
- Secret 使用 `SecretStr`，配置校验错误不会回显已配置的密钥值。
- `AUTO_SEND=true` 在外发安全 Gate 完成前统一拒绝。
- Compose 数据库/MinIO 本地密码支持环境变量覆盖，默认值仅用于本地开发。
