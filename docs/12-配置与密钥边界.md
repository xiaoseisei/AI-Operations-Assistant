# Step 010：配置与密钥边界

> 文档状态：`CONFIG_SECURITY_REVIEW_REQUIRED`
>
> 版本：v0.1；更新时间：2026-09-07

## 配置分层

| 层级 | 内容 | 存放位置 | 规则 |
|---|---|---|---|
| 代码默认值 | `APP_MODE=offline`、`AUTO_SEND=false`、Mock Adapter | `Settings` 默认值 | 安全默认，不连接真实服务 |
| 环境变量 | 环境、模式、Adapter、路径和非敏感开关 | 未追踪 `.env`、CI 环境 | Pydantic 强类型解析；未知字段拒绝 |
| 租户配置 | 语言、跟进策略、模型路由、业务限额 | 后续 PostgreSQL/版本化配置 | 不放入代码默认值；按租户隔离和审计 |
| Restricted Secret | Gmail OAuth、飞书 Secret、LLM API Key、数据库密码 | Docker secrets/KMS/未追踪本地 `.env` | 不进入 Git、日志、Trace、Prompt、SBOM 或错误消息 |

## 模式边界

### Offline + Mock

```dotenv
APP_ENV=local
APP_MODE=offline
AUTO_SEND=false
EMAIL_ADAPTER=mock
LLM_ADAPTER=mock
SQLITE_PATH=.runtime/app.sqlite3
```

不需要任何真实密钥，不连接 Gmail、飞书或真实 LLM；适合本地开发和离线 Demo。`APP_MODE=offline` 若配置真实 Adapter 会启动失败，防止“以为离线、实际连生产”的错误。

### Real/Production

```dotenv
APP_ENV=staging
APP_MODE=real
AUTO_SEND=false
EMAIL_ADAPTER=gmail
LLM_ADAPTER=real
```

Real 模式要求 Gmail Client ID/Secret/Refresh Token、飞书 App ID/Secret 和 LLM API Key 全部存在；任意缺失、空字符串或 Adapter 不匹配都会启动失败，绝不自动降级为 Mock。`AUTO_SEND=true` 在发送安全 Gate 完成前统一拒绝。

## 强类型与启动自检

配置由 `src/ai_ops/config/settings.py` 的 Pydantic Settings 加载：

```powershell
uv run python scripts/config_check.py
```

`AUTO_SEND` 只接受布尔值 `true`/`false`，字符串 `0`、`no`、`yes`、`off` 和空值全部拒绝。自检输出只包含环境、模式、Adapter 和布尔状态，不打印 SecretStr 内容。

## Secret 生命周期

本地开发：从 `.env.example` 复制为未追踪 `.env`，只填入测试凭据；生产使用 Docker secrets 或 KMS。密钥不得写入 Compose、源代码、测试夹具、日志、Trace、Prompt、SBOM 或 Git 历史。泄露时立即撤销、轮换、清理历史并记录脱敏事件。

`.gitignore` 忽略 `.env`、`.runtime/` 和本地数据库；提交前执行：

```powershell
git check-ignore .env .runtime/app.sqlite3
git ls-files | Select-String '\.env$|\.sqlite3$'
```

第二条命令应无输出。

## 验收标准

- Offline + Mock 无真实密钥可通过配置自检。
- Real 模式缺任一必需 Secret 时返回非零并拒绝启动。
- `AUTO_SEND` 默认 `false`，且 `true` 在安全 Gate 前被拒绝。
- `SecretStr` 不以明文出现在 repr、日志或错误消息中。
- 配置测试、Ruff、mypy 和 pytest 通过；状态保持待安全评审，除非责任人完成签字。
