## 一期目标

为一个客户提供可审计的邮件运营闭环：接收 Gmail 入站邮件，识别任务与风险，基于受控知识和最小客户画像生成回复草稿，通过飞书人工审批后发送，并按策略注册可被新邮件取消的跟进计划。

一期的成功不是“模型写出一封话术”，而是每个外部动作都有权限、证据、审批、版本和审计依据；无法证明时安全转人工或阻断。

## In Scope

| 能力域 | 一期承诺 | 用户可见结果 | 最低验收证据 |
|---|---|---|---|
| Gmail 入站与标准化 | 接收入站邮件，解析基本元数据、正文和 Thread 归属；Level 1 Demo 可使用 Mock Adapter | 业务人员能看到一条可追踪的邮件任务 | 入站事件、标准化结果、去重结果、Thread/Run 标识和审计事件 |
| 回复草稿 | 根据任务分类、知识证据和最小画像生成候选草稿 | 业务人员能查看、编辑或拒绝草稿 | 草稿正文、草稿 hash、路由、风险结果、证据引用和版本 |
| 知识库检索 | 从已发布的知识材料读取与任务相关的有限证据 | 草稿中的事实能回指知识来源 | Knowledge Snapshot、文档/片段 ID、检索结果和证据门禁结果 |
| 飞书审批发送 | 将草稿提交飞书审批，支持通过、编辑、拒绝和转人工；发送前再次校验 | 业务人员明确决定是否发送 | 审批卡片/命令、操作者、审批结果、版本校验、Outbox 和 Adapter 结果 |
| 自动跟进 | 对已满足策略的 Thread 注册候选跟进；客户新邮件到达时取消旧计划 | 业务人员能看到计划状态，客户回信后旧计划失效 | 计划 ID、状态变更、失效原因、调度检查和审计记录 |
| 最小客户画像 | 保存证据支持的公司、联系人、角色、需求和偏好候选事实 | 后续草稿能在权限范围内读取可追溯画像 | Profile Delta、source message、evidence span、confidence、observed_at |
| 审计与安全 | 记录路由、审批、发送、拒答、权限、异常和数据访问事件 | 可回答谁在何时基于哪个版本执行了什么 | 不可变审计事件、correlation ID、租户/Thread 范围和安全事件 |

### 集成成熟度说明

Step 001 冻结的是业务能力范围，不把早期 Demo 冒充为真实生产接入。Level 1 Demo 可以使用 Mock Gmail、Mock 飞书和 Mock LLM Adapter；真实 Gmail OAuth、Pub/Sub、History 增量同步、真实飞书应用、持久化底座和生产部署按路线图 Step 036 之后实施。

## 明确不做

| 能力 | 一期处理 | 后续入口 |
|---|---|---|
| CRM/ERP 同步 | 不接入、不读取、不回写；客户请求记录为二期候选 | 独立连接器与权限评审 |
| Slack/企微/Microsoft 365 | 不实现渠道 Adapter | 场景扩展专项评审 |
| 批量营销或群发 | 不提供群发任务、营销名单和自动触达 | 营销合规与发送策略专项 |
| 合同/价格/退款自动动作 | 不修改合同、承诺价格、发起退款或付款 | 业务规则与人工审批专项 |
| 无审批直发 | 一期所有外发邮件必须人工审批 | 后续信任分级和独立 Gate |
| 跨客户画像共享 | 画像严格按客户/租户/Thread 权限隔离 | 多租户平台专项评审 |
| 开放式 Shell/浏览器工具 | Agent 不得执行任意 Shell、脚本或开放网络操作 | 工具 Allowlist 安全评审 |
| 生产多租户平台化 | 早期按每客户独立 Docker Compose 部署，不做平台化运营 | 多租户隔离与计费专项 |
| 未经安全评审的附件执行 | 可记录和隔离附件，不执行附件中的命令、宏或任意网络请求 | 隔离解析和恶意文件专项 |

以下内容同样不属于一期承诺：自动删除邮件、替客户登录其他系统、读取无关邮箱、跨租户错误恢复、基于自然语言记忆的无证据事实写入，以及把模型的“低风险”结论当作唯一放行依据。

### 变更流程

客户临时要求 CRM 同步、自动直发或其他明确不做项时，不改变一期 Gate。必须先创建变更请求，补充业务价值、受影响的风险等级、额外数据和权限、UAT 场景、回滚方案、责任人和目标版本；业务、技术、安全/交付责任人完成评审前，状态保持 `PROPOSED`，不得进入一期实施任务。

涉及外发策略、客户数据、OAuth Scope、跨租户边界或不可逆动作的变更，即使看似“只是配置”，也必须重新经过安全和技术评审。

## 一期硬边界

1. 所有外发邮件默认必须经过人工审批；缺少匹配审批记录、草稿 hash、权限、证据或当前策略版本时，Adapter 不得发送。
2. 投诉、退订、退款/合同、报价/折扣、越权、Prompt Injection、恶意附件和证据冲突不得自动外发；按任务契约转人工、抑制或隔离。
3. 客户新邮件到达后，已有跟进计划必须进入失效流程；不能因调度任务已经创建就继续发送旧跟进。
4. 最小画像只接受带来源和证据的候选事实；推测、臆测、无来源自然语言指令不得持久化。
5. 无法确认租户、Thread、权限、版本、数据分类或发送结果时，默认只读/人工处理，并保留可查询审计证据。
